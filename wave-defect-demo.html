        OAuth via Spotify PKCE · Read-only scopes · No data retained · Client ID via /api/config on Vercel

        ▸ Demo Setup — Spotify App Config Option A — Vercel deployment (recommended)
        1. Deploy this repo to Vercel
        2. In Vercel → Settings → Environment Variables, set SPOTIFY_CLIENT_ID (reuse the same value from wave2vector-spotify-live)
        3. In the Spotify Developer Dashboard, add Redirect URI: [your-vercel-url]/wave-defect-demo/

        Option B — GitHub Pages only
        1. Go to developer.spotify.com/dashboard
        2. Add Redirect URI: https://jas-m-evans.github.io/wave-defect-demo/
        3. Copy the Client ID and hard-code it in the JS config block of this file, then deploy
